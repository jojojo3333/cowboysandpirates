# world/research

Reports commissioned from outside this repo — usually from a model that cannot
run the code, which is exactly what research is good for.

**Put new reports here, not in `assets/`.** `assets/` ships in the web export,
so a document dropped there is downloaded by every player. Nothing in `world/`
is exported.

Name them `YYYY-MM-DD-topic.ext` so the order is obvious. Anything acted on
should leave a trace in `BACKLOG.md` saying what was taken from it — a report
nobody acted on is just a file.
